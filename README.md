# DJ Audio Mixer (C++)

A C++ DJ mixing software project that implements real-time audio playback and mixing using a modular, component-based design.  
The project focuses on core audio processing logic, performance considerations, and clean, maintainable C++ architecture.

## Features
- Real-time audio playback for multiple tracks
- Crossfader and channel isolation logic
- Modular design using C++ source (.cpp) and header (.h) files
- Waveform visualization and playlist management components
- Performance-focused implementation suitable for audio applications

## Tech Stack
- C++
- JUCE Framework
- Modular C++ source and header files

## What I Learned
- Structuring medium-sized C++ applications with multiple interacting components
- Separating interface (.h) and implementation (.cpp) for maintainability
- Fundamentals of real-time audio processing and playback
- Designing UI and audio logic using a component-based approach
- Writing clean, readable, and extensible C++ code

## Build / Run
This project is built using the JUCE framework.

1. Open the `.jucer` file in **Projucer**
2. Generate the project for your target IDE (Visual Studio / Xcode)
3. Build and run the project from the generated IDE files

> Build instructions may vary depending on platform and JUCE version.
