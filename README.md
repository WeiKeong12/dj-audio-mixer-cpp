# DJ Audio Mixer (C++)

A C++ DJ mixing software project that implements real-time audio mixing using modular source and header files.  
The project focuses on core audio processing logic, performance, and clean C++ design.

## Features
- Audio mixing logic for multiple tracks
- Modular design using C++ source and header files
- Performance-focused implementation

## Tech Stack
- C++
- C++ Header Files

## What I Learned
- Structuring medium-sized C++ projects
- Separating interface (.h) and implementation (.cpp)
- Basics of real-time audio processing
- Writing clean, maintainable C++ code
